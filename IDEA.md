# Project Idea

POC to visualise the policies in Azure API Management, using the equivalent of the "calculate effective policy" function in APIM, and then to have the process visualised.  Connect to an APIM instance using the current user's credentials via the DefaultAzureCredential class, and allow for dynamic selection of the level at which the effective policy is to be calculated.  Then calculate the effective policy and use the resultant XML to show the logic flow represented by that XML, with branching, flow control, and so on. For the purpose of testing and debugging, use the current az CLI login context, and query a configurable existing APIM instance, defaulted to the resource apim-zlyway6g7icoy. Create a visually appealling web site, with no need for mobile support.
